Project: CA Compliance Due-Date Tracker
A clean web app for tracking GST, Income Tax, TDS, ROC, Audit and other professional deadlines.

Core features:
- 📅 Add compliance/task with due date
- 🔴 Overdue automatically highlighted
- 🟠 Due within 7 days
- 🟢 Completed
- ⏳ Countdown: 3 days remaining
- 🔎 Search and filter
- 👤 Client-wise tracking
- 🏷️ Compliance type/category
- 📝 Notes
- 🔔 Browser reminders
- 📊 Dashboard:
  - Total
  - Overdue
  - Due today
  - Due this week
  - Completed
- 💾 Data saved in browser
- 📤 Export to Excel/CSV
- 📱 Mobile responsive
- 🌐 GitHub Pages compatible
